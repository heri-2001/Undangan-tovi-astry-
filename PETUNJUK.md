# Petunjuk
1. Ganti foto: simpan foto asli pasangan sebagai `foto/pasangan.jpg` (menimpa file sementara). Foto galeri taruh di folder `foto/`.
2. Buka `config.js`: isi nomorWA, mapGereja, mapResepsi, daftar galeri.
3. Musik: letakkan file `musik.mp3` (yang Anda punya hak pakainya) di folder utama.
4. Coba di komputer: klik dua kali `index.html`.
5. Publikasi gratis: buat akun github.com > New repository (nama: undangan, Public) > Add file > Upload files > unggah SEMUA isi folder > Commit. Lalu Settings > Pages > Source: Deploy from a branch > main / root > Save. Tunggu 1-2 menit, link: https://USERNAME.github.io/undangan/
6. Nama tamu: tambahkan `?to=Nama%20Tamu` di akhir link, contoh .../undangan/?to=Bapak%20Yohanes
